# Lolia, The Lazy Perfectionist

One-page link hub. A single self-contained `index.html` (photos are embedded), no build step.

To connect the portfolios, open `index.html`, find the two `data-soon` links (`href="#dev"` and `href="#content"`), replace the `href` with the real URL, add `target="_blank" rel="noopener"`, and delete the `data-soon="..."` attribute and the `<span class="soon">soon</span>` tag.
